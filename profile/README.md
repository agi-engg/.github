# agi-engg

**Production Frappe / ERPNext apps and AI tooling.** Built by the team behind [LazyChat](https://github.com/soumyasethy/lazychat-erpnext).

We ship open-source pieces from a Shopify-class e-commerce stack running end-to-end on ERPNext.

### What's here

- **[india-banking](https://github.com/agi-engg/india-banking)** — ERPNext integration for 5 Indian banks (ICICI, HDFC, AXIS, YES, Kotak Mahindra). Vendor payouts, payroll, reconciliation, virtual accounts.
- **[India-Banking-H2H](https://github.com/agi-engg/India-Banking-H2H)** — Frappe app for secure, automated Host-to-Host bank integrations.
- **[frappe-docker](https://github.com/agi-engg/frappe-docker)** — our production Frappe Docker setup.
- **[erp-pim-agilitas](https://github.com/agi-engg/erp-pim-agilitas)** · **[erp-mes](https://github.com/agi-engg/erp-mes)** — PIM and MES apps used in our production stack.

### Adjacent — but not in this org

- **[lazychat-erpnext](https://github.com/soumyasethy/lazychat-erpnext)** — AI assistant docked into the ERPNext desk. 101-tool MCP server, BYO LLM.

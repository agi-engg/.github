# agi-engg

**Production Frappe / ERPNext apps and AI tooling.** Built by the team behind [LazyChat](https://github.com/soumyasethy/lazychat-erpnext).

We run a Shopify-class e-commerce stack end-to-end on ERPNext — manufacturing to last-mile delivery. Most of the stack is private; the pieces we open-source live here.

### Open source

- **[india-banking](https://github.com/agi-engg/india-banking)** — ERPNext integration for 5 Indian banks (ICICI · HDFC · AXIS · YES · Kotak Mahindra). Vendor payouts, payroll payouts, statement reconciliation, virtual accounts.

### Adjacent — but not in this org

- **[lazychat-erpnext](https://github.com/soumyasethy/lazychat-erpnext)** — AI assistant docked into the ERPNext desk. 101-tool MCP server, BYO LLM (any OpenAI-compatible or Anthropic key, stays in your browser). The Frappe community's first AI-native sidekick.
